Client Module

The Client module provides the high-level interface for creating and managing Discord bots.

Bot

Nobelium.Client.Bot — Type
Bot

Main Discord bot client that coordinates REST, Gateway, and Cache modules.

Fields

  • config::ClientConfig: Client configuration
  • rest::RESTClient: REST API client
  • gateway::GatewayConnection: Gateway WebSocket connection
  • cache::DiscordCache: Local cache for Discord objects
  • user::Union{User, Nothing}: Bot's own user (populated after READY)
  • application_id::Union{Snowflake, Nothing}: Bot's application ID (populated after READY)
  • running::Bool: Whether the bot is currently running

Example

bot = Bot(token = "YOUR_BOT_TOKEN", intents = Intents.DEFAULT)

on!(bot, "MESSAGE_CREATE") do data
    println("Received message: ", data["content"])
end

start!(bot)

Lifecycle Functions

Nobelium.Client.start! — Function
start!(bot::Bot)

Start the bot by connecting to the Discord Gateway and beginning the event loop.

This function blocks until the bot is stopped or disconnected.

Example

bot = Bot(token = "YOUR_TOKEN")
start!(bot)  # Blocks until stopped
source
start!(manager::ShardManager)

Start all shards with proper rate limiting.

Shards are started in batches according to max_concurrency, with a 5-second delay between batches as required by Discord.

Event Handling

Nobelium.Client.on! — Function
on!(bot::Bot, event::String, handler::Function)

Register an event handler for a Gateway event.

Arguments

  • bot::Bot: The bot instance
  • event::String: Event name (e.g., "MESSAGECREATE", "GUILDCREATE")
  • handler::Function: Handler function that receives event data as a Dict

Example

on!(bot, "MESSAGE_CREATE") do data
    println("Message: ", data["content"])
end
source
on!(manager::ShardManager, event::String, handler::Function)

Register an event handler for all shards.

If shards are already created, the handler is added to all existing shards. The handler is also stored to be applied to any future shards.

Arguments

  • manager::ShardManager: The shard manager
  • event::String: Event name
  • handler::Function: Handler function

Example

on!(manager, "MESSAGE_CREATE") do data
    println("Message: ", data["content"])
end
source

Configuration

Nobelium.Client.ClientConfig — Type
ClientConfig

Configuration for a Discord bot client.

Fields

  • token::String: Bot token for authentication
  • intents::UInt32: Gateway intents specifying which events to receive
  • shard_id::Union{Int, Nothing}: Shard ID for this client (0-indexed)
  • num_shards::Union{Int, Nothing}: Total number of shards
  • cache_config::CacheConfig: Configuration for caching behavior

Example

config = ClientConfig(
    "YOUR_BOT_TOKEN";
    intents = Intents.DEFAULT | Intents.MESSAGE_CONTENT,
    cache_config = CacheConfig(guilds_limit = 1000)
)

Sharding

For large bots that need to distribute load across multiple Gateway connections:

Nobelium.Client.ShardManager — Type
ShardManager

Manages multiple bot shards for large-scale Discord bots.

Discord requires bots in many guilds to use sharding, where each shard handles a subset of guilds. The ShardManager coordinates multiple shard connections, respecting Discord's rate limits for shard identification.

Fields

  • config::ClientConfig: Base configuration (token, intents, cache config)
  • shards::Vector{Bot}: Vector of bot instances, one per shard
  • num_shards::Int: Total number of shards
  • max_concurrency::Int: Maximum concurrent shard identifications
  • running::Bool: Whether the manager is running
  • shard_tasks::Vector{Task}: Background tasks for each shard

Example

# Create a manager for 4 shards
config = ClientConfig("YOUR_TOKEN"; intents = Intents.DEFAULT)
manager = ShardManager(config, 4; max_concurrency = 1)

# Register event handlers (applied to all shards)
on!(manager, "MESSAGE_CREATE") do data
    println("Message on shard: ", data["content"])
end

# Start all shards
start!(manager)
source

Example Usage

Basic Bot

using Nobelium

bot = Bot(
    token = ENV["DISCORD_TOKEN"],
    intents = Intents.DEFAULT | Intents.MESSAGE_CONTENT
)

on!(bot, "MESSAGE_CREATE") do data
    if data["content"] == "!ping"
        reply(bot, data; content = "Pong!")
    end
end

start!(bot)

Sharded Bot

using Nobelium

# Create a shard manager for 4 shards
manager = ShardManager(ENV["DISCORD_TOKEN"], 4;
    intents = Intents.DEFAULT
)

# Register handlers (applied to all shards)
on!(manager, "MESSAGE_CREATE") do data
    println("Message on shard: ", data)
end

start!(manager)
