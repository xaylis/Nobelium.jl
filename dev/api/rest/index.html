REST Module

The REST module provides HTTP client functionality for Discord's REST API v10.

RESTClient

Nobelium.REST.RESTClient — Type
RESTClient

HTTP client for Discord REST API with automatic rate limiting.

Fields

  • token::String: Bot token (without "Bot " prefix)
  • api_version::Int: API version to use (default: 10)
  • rate_limiter::RateLimiter: Rate limiter instance
  • max_retries::Int: Maximum number of retries for rate limited requests

Example

client = RESTClient("YOUR_BOT_TOKEN")
response = request(client, :GET, "/users/@me")

Rate Limiting

The REST client automatically handles rate limits. When a rate limit is hit, requests are delayed until the limit resets.

Nobelium.REST.RateLimiter — Type
RateLimiter

Manages rate limiting for Discord API requests.

Tracks per-route buckets and handles global rate limits.

Fields

  • buckets::Dict{String, Bucket}: Map of route keys to their rate limit buckets
  • bucket_ids::Dict{String, String}: Map of route keys to bucket IDs
  • global_lock::ReentrantLock: Lock for global rate limit state
  • global_reset::Atomic{Float64}: Unix timestamp when global rate limit resets
  • global_condition::Condition: Condition variable for pausing during global rate limit
  • lock::ReentrantLock: Lock for bucket dictionary access
source
Nobelium.REST.acquire! — Function
acquire!(limiter::RateLimiter, method::Symbol, endpoint::String)::Nothing

Acquire permission to make a request, waiting if rate limited.

This function blocks until the request can be made without violating rate limits. It checks both global rate limits and per-bucket rate limits.

Arguments

  • limiter::RateLimiter: The rate limiter
  • method::Symbol: HTTP method
  • endpoint::String: API endpoint

Returns

Nothing. The function blocks until the request can proceed.

source
Nobelium.REST.update! — Function
update!(limiter::RateLimiter, method::Symbol, endpoint::String, headers::Dict{String, String})::Nothing

Update rate limit state from response headers.

Parses Discord's rate limit headers and updates the appropriate bucket.

Headers parsed:

  • X-RateLimit-Bucket: Unique bucket identifier
  • X-RateLimit-Limit: Maximum requests per window
  • X-RateLimit-Remaining: Requests remaining in current window
  • X-RateLimit-Reset: Unix timestamp when the bucket resets
  • X-RateLimit-Reset-After: Seconds until the bucket resets

Arguments

  • limiter::RateLimiter: The rate limiter
  • method::Symbol: HTTP method
  • endpoint::String: API endpoint
  • headers::Dict{String, String}: Response headers

Example Usage

Direct REST Client Usage

using Nobelium.REST

client = RESTClient("Bot YOUR_TOKEN")

# Get current user
user = get_current_user(client)

# Send a message
message = create_message(client, channel_id;
    content = "Hello from REST!",
    embeds = [Dict("title" => "Embed", "description" => "Content")]
)

# Upload a file
file = FileUpload(
    name = "file",
    data = IOBuffer("Hello, World!"),
    filename = "hello.txt",
    content_type = "text/plain"
)
create_message(client, channel_id;
    content = "Here's a file!",
    files = [file]
)

Error Handling

try
    message = create_message(client, channel_id; content = "Test")
catch e::APIError
    println("Status: ", e.status_code)
    println("Error: ", e.message)
    println("Endpoint: ", e.endpoint)
catch e::RateLimitError
    println("Rate limited for ", e.retry_after, " seconds")
    println("Global: ", e.is_global)
end
