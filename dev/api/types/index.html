Types Module

The Types module defines all Discord data structures and JSON serialization.

Snowflake

Discord uses snowflake IDs - 64-bit integers that encode timestamp and other metadata.

Nobelium.Types.Snowflake — Type
Snowflake

A primitive type wrapping a UInt64 representing a Discord snowflake ID.

source
Nobelium.Types.timestamp — Function
timestamp(s::Snowflake) -> DateTime

Extract the creation timestamp from a Snowflake. Returns the DateTime when this ID was generated.

source
Nobelium.Types.worker_id — Function
worker_id(s::Snowflake) -> UInt8

Extract the internal worker ID from a Snowflake (5 bits, 0-31).

source
Nobelium.Types.process_id — Function
process_id(s::Snowflake) -> UInt8

Extract the internal process ID from a Snowflake (5 bits, 0-31).

source
Nobelium.Types.increment — Function
increment(s::Snowflake) -> UInt16

Extract the increment value from a Snowflake (12 bits, 0-4095). This is used to differentiate IDs generated in the same millisecond.

source

Snowflake Usage

using Nobelium.Types: Snowflake, timestamp

# Create from various types
id = Snowflake(123456789012345678)
id = Snowflake("123456789012345678")
id = Snowflake(UInt64(123456789012345678))

# Convert back
UInt64(id)
string(id)

# Extract timestamp
timestamp(id)  # Returns DateTime

Nobelium.Types.lower_discord_type — Function
lower_discord_type(x::T) where T -> Dict{String, Any}

Convert a Discord type to a Dict for JSON serialization. Handles the distinction between optional and nullable fields:

  • Fields set to nothing are omitted entirely
  • Fields set to missing are included as JSON null
  • Fields with values are included normally

This is used for PATCH requests where omitting a field means "don't change" and sending null means "clear this value".

source

Optional vs Nullable Fields

Nobelium distinguishes between optional and nullable fields:

  • nothing - Field is omitted from JSON (don't change this value)
  • missing - Field is explicitly null in JSON (clear this value)
  • T - Field has a value
# Example: Modifying a guild
# To keep current name, set to nothing (omit from request)
# To clear description, set to missing (send null)
# To set new value, provide the value

modify_guild(client, guild_id;
    name = nothing,        # Keep current name
    description = missing, # Clear description
    icon = "base64data"    # Set new icon
)
