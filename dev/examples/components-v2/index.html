Components V2 Example

This example demonstrates how to use the new Discord Components V2 which allows for richer message layouts.

Overview

Components V2 introduces layout components (Sections, Containers, Separators) and content components (Text Display, Media Gallery, Thumbnail) that replace the legacy content and embeds fields.

When using any V2 component, Nobelium automatically handles the necessary flags (IS_COMPONENTS_V2).

Creating Complex Layouts

Here is an example of a message using various V2 components.

using Nobelium

# Create media items
# Note: In a real app, you might use proxy_url or attachment IDs
media_item = unfurled_media("https://example.com/image.png"; 
    width=300, 
    height=200
)

# 1. Create a Section
# Sections are top-level layout units. They can have an accessory.
welcome_section = section(
    components=[
        text_display("## Welcome to the Server!\nWe are glad to have you here.")
    ],
    accessory=thumbnail(media_item)
)

# 2. Create a Media Gallery
gallery = media_gallery([
    media_gallery_item(media_item; description="Scene 1"),
    media_gallery_item(media_item; description="Scene 2")
])

# 3. Create a Container
# Containers group content visually, optionally with an accent color.
info_container = container(
    components=[
        text_display("This is a container"),
        separator(spacing=SeparatorSpacing.SMALL),
        text_display("It has a small separator inside.")
    ],
    accent_color=0x5865F2 # Discord Blurple
)

# 4. Interactive Elements (Action Row)
# Standard buttons still work and can be mixed in.
buttons = action_row(
    button(label="Accept Rules", style=ButtonStyles.SUCCESS, custom_id="accept"),
    button(label="Help", style=ButtonStyles.SECONDARY, custom_id="help")
)

# Send the message
# Nobelium automatically detects V2 components and sets the IS_COMPONENTS_V2 flag.
send_message(bot, channel_id;
    components=[
        welcome_section,
        separator(spacing=SeparatorSpacing.LARGE),
        gallery,
        info_container,
        buttons
    ]
)

Important Notes

  1. No Content/Embeds: When using V2 components, you cannot use the legacy content string or embeds array. Use text_display and section components instead.
  2. Top-Level Structure: Messages are composed of a list of top-level components. section, container, media_gallery, and action_row are common top-level items.
  3. Automatic Flags: You do not need to manually set the IS_COMPONENTS_V2 flag; the library does this for you if it detects any V2 component types.
