Getting Started

This guide will walk you through setting up your first Discord bot using Nobelium.jl.

Prerequisites

  • Julia 1.9 or later
  • A Discord account
  • A Discord bot token (see Creating a Bot Application)

Installation

Install Nobelium.jl using Julia's package manager:

using Pkg
Pkg.add("Nobelium")

Or in the Julia REPL:

] add Nobelium

Creating a Bot Application

  1. Go to the Discord Developer Portal
  2. Click "New Application" and give it a name
  3. Go to the "Bot" section in the left sidebar
  4. Click "Add Bot" and confirm
  5. Under "Token", click "Copy" to copy your bot token
Keep your token secret!

Never share your bot token or commit it to version control. Use environment variables to store it securely.

Inviting Your Bot to a Server

  1. In the Developer Portal, go to "OAuth2" → "URL Generator"
  2. Select the "bot" scope
  3. Select the permissions your bot needs (e.g., "Send Messages", "Read Message History")
  4. Copy the generated URL and open it in your browser
  5. Select a server and authorize the bot

Your First Bot

Create a new file called bot.jl:

using Nobelium

# Create a bot client with your token
bot = Bot(
    token = ENV["DISCORD_TOKEN"],
    intents = Intents.DEFAULT | Intents.MESSAGE_CONTENT
)

# Respond to !ping command
on!(bot, "MESSAGE_CREATE") do data
    if data["content"] == "!ping"
        reply(bot, data; content = "Pong! 🏓")
    end
end

# Log when the bot is ready
on!(bot, "READY") do data
    println("Bot is ready! Logged in as: ", data["user"]["username"])
end

# Start the bot (this blocks)
start!(bot)

Run your bot:

export DISCORD_TOKEN="your-bot-token-here"
julia bot.jl

Understanding Intents

Intents tell Discord which events your bot wants to receive. Common intents include:

IntentDescription
Intents.GUILDSGuild create/update/delete events
Intents.GUILD_MESSAGESMessage events in guilds
Intents.DIRECT_MESSAGESMessage events in DMs
Intents.MESSAGE_CONTENTAccess to message content (privileged)
Intents.GUILD_MEMBERSMember events (privileged)
# Combine intents with bitwise OR
intents = Intents.GUILDS | Intents.GUILD_MESSAGES | Intents.MESSAGE_CONTENT

# Or use presets
intents = Intents.DEFAULT  # Common non-privileged intents
intents = Intents.ALL      # All intents (requires privileged access)
Privileged Intents

MESSAGE_CONTENT, GUILD_MEMBERS, and GUILD_PRESENCES are privileged intents. You must enable them in the Discord Developer Portal under "Bot" → "Privileged Gateway Intents".

Sending Messages

# Send a message to a channel
send_message(bot, channel_id; content = "Hello, World!")

# Send with an embed
embed = Dict(
    "title" => "My Embed",
    "description" => "This is an embedded message",
    "color" => 0x5865F2  # Discord blurple
)
send_message(bot, channel_id; embeds = [embed])

# Reply to a message
on!(bot, "MESSAGE_CREATE") do data
    reply(bot, data; content = "I saw your message!")
end

Event Handling

Register handlers for Discord events:

# Handle new messages
on!(bot, "MESSAGE_CREATE") do data
    println("New message: ", data["content"])
end

# Handle guild joins
on!(bot, "GUILD_CREATE") do data
    println("Joined guild: ", data["name"])
end

# Handle reactions
on!(bot, "MESSAGE_REACTION_ADD") do data
    println("Reaction added: ", data["emoji"]["name"])
end

Error Handling

Nobelium provides typed errors for better error handling:

try
    send_message(bot, channel_id; content = "Hello!")
catch e::APIError
    println("API Error: ", e.message)
    println("Status: ", e.status_code)
catch e::RateLimitError
    println("Rate limited! Retry after: ", e.retry_after, " seconds")
catch e::GatewayError
    println("Gateway error: ", e.reason)
end
