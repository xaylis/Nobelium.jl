Nobelium.jl

A Discord API wrapper for Julia.

Features

  • Full Discord REST API v10 coverage
  • Gateway WebSocket connection with automatic reconnection
  • Automatic rate limit handling
  • Type-safe Discord objects with JSON serialization
  • Slash commands, buttons, select menus, and modals
  • Voice channel support with Opus audio
  • Thread-safe caching with configurable limits
  • Sharding support for large bots

Installation

using Pkg
Pkg.add("Nobelium")

Quick Start

using Nobelium

# Create a bot client
bot = Bot(
    token = ENV["DISCORD_TOKEN"],
    intents = Intents.DEFAULT | Intents.MESSAGE_CONTENT
)

# Register an event handler
on!(bot, "MESSAGE_CREATE") do data
    if data["content"] == "!ping"
        send_message(bot, data["channel_id"]; content = "Pong!")
    end
end

# Start the bot
start!(bot)
